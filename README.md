# maxelor

A site showcasing my work as a mobile developer.

## Structure

- `index.md` — the home page, served at `/`.
- `_layouts/default.html` — minimal layout (centered container).
- `assets/css/style.css` — minimal styles (CSS variables, no framework).
- `assets/images/` — site images.
- `_config.yml`, `Gemfile` — Jekyll configuration

## Local development

```bash
bundle install
bundle exec jekyll serve
```

Then open [http://localhost:4000](http://localhost:4000).
